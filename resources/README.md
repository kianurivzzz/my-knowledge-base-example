# Полезные ресурсы

- [OWASP Cheat Sheet Series](https://cheatsheetseries.owasp.org) — короткие
  руководства по защите приложений.
- [Документация Nmap](https://nmap.org/book/man.html) — официальное описание
  ключей и режимов сканирования.
- [Have I Been Pwned](https://haveibeenpwned.com) — проверка адреса почты по
  известным утечкам.
