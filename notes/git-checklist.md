# Чек-лист работы с репозиторием

1. Перед началом работы забрать свежее состояние: git pull.
2. Новую правку делать в отдельной ветке.
3. Проверять git status до коммита.
4. Писать сообщение коммита так, чтобы было понятно, что изменилось.
5. Перед слиянием просматривать список изменений на Files changed.
