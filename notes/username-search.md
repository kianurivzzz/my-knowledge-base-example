# Поиск по никнейму

Методика поиска по никнейму строится от общего к частному.
Сначала проверяются поисковые системы с точной фразой в кавычках.
Затем никнейм проверяется на популярных площадках по прямому адресу профиля.
Найденные профили сверяются между собой по аватару, дате регистрации и стилю.
Совпадение никнейма само по себе ничего не доказывает, его нужно подтверждать.
Все проверки выполняются только на вымышленных примерах и учебных аккаунтах.
