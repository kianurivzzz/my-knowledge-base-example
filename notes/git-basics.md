- git status: показывает, что изменилось с последнего коммита
- git add: отбирает изменения для коммита
- git commit: сохраняет отобранное в историю
- git push: отправляет коммиты на GitHub
- git pull: забирает изменения с GitHub и обновляет файлы
- git switch -c: создаёт ветку и переходит в неё
- git merge: приносит изменения из другой ветки в текущую
- git branch -d: удаляет ветку после слияния
- git push -u origin имя: отправляет ветку на GitHub в первый раз
- Pull Request: заявка на слияние ветки в main, открывается на GitHub
